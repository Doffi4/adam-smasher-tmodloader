## Adam Smasher 0.1.5

A Cyberpunk-inspired boss for late-endgame Calamity: marked missile strikes, aimed gunfire and Sandevistan dash sequences. Each reward roll gives exactly one weapon: **50% Annihilation Protocol (magic) / 50% Arasaka Mantis Blades (melee)**.

### Fixed

Attack warnings remain eligible for drawing when the boss or delivery rocket is off-screen. Combat balance, weapons and loot are unchanged from 0.1.4.

### Install and summon

1. Install **Calamity Mod** in tModLoader.
2. Download **AdamSmasher.tmod**, copy it into your profile's `Mods` folder, enable it and restart tModLoader.
3. Use **0.1.5 on the server and every client**.

Craft the reusable **Arasaka Beacon** with **5 Shadowspec Bars + 25 Mysterious Circuitry + 25 Dubious Plating** at **Draedon's Forge**. Use it while no other boss is active.

Calamity Mod Music is optional. [Full English guide](https://github.com/Doffi4/adam-smasher-tmodloader/blob/main/README.md).

### Verification

Build: zero errors and warnings. Passed 27 boss test groups, weapon/mana and lifecycle checks, 1,000 actual treasure-bag openings, recipe/localization/BossChecklist checks and isolated loading with Calamity. Public sources were compiled separately.

Live multiplayer transport, GPU appearance, the full third-party modpack and equipped-character balance still need in-game testing. [Test report](https://github.com/Doffi4/adam-smasher-tmodloader/blob/main/docs/TESTING.md).
